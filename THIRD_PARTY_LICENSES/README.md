# Third-party license texts

This directory contains the license texts needed by the Windows installer and
portable archive. `THIRD_PARTY_NOTICES.md` maps each distributed component to
its source, version, license and file here.

The directory is copied without modification into formal Windows distribution
packages. Do not remove a license merely because the Python dependency is not
imported on a developer machine; verify the final PyInstaller artifact first.

Qt/PySide6 corresponding-source delivery is tracked separately in
`THIRD_PARTY_SOURCE.md`. Asset permissions that are not software licenses are
tracked in `ASSET_LICENSES.md`.
