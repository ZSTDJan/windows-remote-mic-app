# 无线麦 Windows 使用说明

无线麦把小米遥控器2 Pro 和图示谷歌 Chromecast 遥控器变成 Windows 的远程按键和语音输入设备。

**[下载页面与最新版说明](https://github.com/ZSTDJan/windows-remote-mic-app)** · [历史版本](https://github.com/ZSTDJan/windows-remote-mic-app/releases)

## 下载与升级

- **最低系统要求为 x64 Windows 10 1809 或更新版本。** 软件主要在 Windows 11 上验证。Windows 10 的蓝牙兼容性仍在验证，部分谷歌遥控器与蓝牙驱动组合可能出现服务启动失败、按键无响应或断线。
- 使用免安装 ZIP，完整解压到新文件夹，再运行文件夹顶层的无线麦 EXE；不要只把 EXE 单独取出来。
- 升级前从通知区域选择“完全退出”，把新 ZIP 解压到新文件夹，再运行新版。同机同一 Windows 账户下自动沿用原配置。
- 程序未签名，Windows 可能显示安全提示。请从本仓库下载，并核对同次发布的 `SHA256SUMS.txt`。

核对下载文件：

```powershell
Get-FileHash -Algorithm SHA256 .\RemoteMicRC003-<版本号>-portable-unsigned.zip
```

结果应与清单中同名文件的哈希一致。

## 第一次使用

- **首次配置前，请先暂时退出 360 等杀毒软件；配置和测试完成后恢复防护。**
- **首次使用语音前，必须先安装 VB-CABLE 并重启电脑。**
- 杀毒软件可能误报或隔离无线麦，造成启动、按键或语音异常。核实下载来源和 SHA-256，确认为误报后再恢复文件。
- 可将无线麦程序或其专用安装／解压目录加入信任或白名单，范围仅限无线麦，保留其它防护。

### 1. 配对遥控器

在 Windows“设置 → 蓝牙和设备”中完成配对。小米遥控器2 Pro 同时长按“主页键 + 菜单键”进入配对状态；谷歌遥控器请按实物型号说明操作。

### 2. 选择设备并连接

1. 打开无线麦“设备”页，点击“选择设备”。
2. 选中遥控器，点击“使用此设备”。
3. 点击“启动服务”，按页面提示处理未就绪状态。
4. 连接后按一次方向键或确定键，确认能控制电脑。

程序会记住选中的遥控器。切换设备时会先结束当前按键和录音，再连接新设备。

### 3. 设置按键

在“按键”页选择实体按键，分别设置单击、双击和长按动作，点击“完成”保存。

- 可设置方向、确认、返回、音量、翻页、快捷键、鼠标操作、Quicker、输入文字或打开程序。
- 普通长按动作触发一次；允许连续执行的动作会在持续按住时重复。
- 只有实体话筒键能传送遥控器声音，其它按键不能改成语音键。
- 需要管理员按键组件时会出现 UAC 提示；取消后自定义映射不会生效，可回到“设备”页重新启用或修复。

#### 输入文字

1. 动作选择“输入文字”，在“预设文字”框填写正文，再点“完成”。支持中文、表情和多行，最多 10000 个字符。
2. 把光标放在目标输入框，再按遥控器。正文会粘贴一次，剪贴板保留该内容，不额外按回车，也不长按连发。

正文中的快捷键名称或 Quicker 链接只会作为文字输入。目标程序需支持粘贴；剪贴板被占用、焦点改变或其它修饰键未松开时，回到输入框后再试。

#### 打开程序

1. 动作选择“打开程序”，填写完整的 `.exe` 路径，或点击“浏览…”选择文件，再点“完成”。
2. 按遥控器启动程序。每次触发只请求启动一次，长按不连发。

支持中文、空格及复制路径时外侧的一对双引号；暂不支持启动参数和快捷方式。程序移动或换电脑后需重新选择路径；已运行的程序能否显示原窗口，取决于该程序。

#### 鼠标长按

“长按”栏可选鼠标左键、右键、X1、X2 长按。按住约 0.55 秒后保持鼠标按下，松开遥控器按键即释放。

#### 保存和切换按键方案

点击“恢复内置默认”旁的“管理按键配置”：

- 日常修改会自动保存到“自动保存”项。要保留一套方案，点击“复制配置”并命名。
- 选中方案后点击“应用配置”并确认；只浏览列表不会切换。正在使用的方案带勾并加粗。
- 可重命名、删除副本，或导出／导入 JSON 文件。导入后仍需点击“应用配置”才生效。
- 方案按遥控器型号区分，只包含按键动作和备注，不包含蓝牙配对、语音或音频设置。
- “自动保存”项不能删除；删除副本不会清除当前映射。提示旧动作需调整时，先修改并保存当前按键，再管理副本。

### 4. 设置语音

**无线麦和所用输入法两边都要配置。**

1. 在“语音”页点击“安装音频”，安装 VB-CABLE，**完成后先重启电脑**。
2. 在无线麦中选择语音程序，“输出端点”选择 `CABLE Input — Windows WASAPI`；没有 WASAPI 时可选 `Windows DirectSound`，不要选 `Windows WDM-KS`。
3. 在对应输入法或 Chatterfly 的麦克风设置中选择 `CABLE Output`。
4. 搜狗、微信和豆包需在两边选择相同的语音模式，并核对“语音按键”快捷键一致；可刷新读取或手动录入。
5. 在记事本输入框中，先用实体键盘测试语音快捷键，再用遥控器话筒键测试。Chatterfly 直接控制录音，无需快捷键。

`CABLE Input` 是无线麦写入声音的一侧，`CABLE Output` 是输入法读取麦克风的一侧，不能选反。

遥控器的使用方式：

- 按住型：按住话筒键说话，松开结束；小米和谷歌均支持。
- 开关型：按一次开始，再按一次结束；仅谷歌支持，自动结束时长可选 1、2、3、5 或 10 分钟。
- 搜狗、微信和豆包的开关型还需配置对应快捷键。按住型录音时快捷键会一直按下，请避开其它软件的常用组合键。

手动录入的快捷键不会被自动替换，需要时点击刷新；微信读取快捷键也需主动刷新。

### 豆包更新

- 豆包更新后，遥控语音可能暂时不可用。
- 建议关闭豆包自动更新，确认无线麦兼容后再手动更新。

## 日常使用

- 关闭设置窗口默认只是隐藏到通知区域，遥控器服务继续运行；退出请右键图标选择“完全退出”。
- “随 Windows 启动”和“启动程序时自动运行服务”可分别设置。
- 服务断开后按设备页提示重新连接；若持续失败，按下方方法反馈。
- “检查更新”只提示和下载新版，不会自动运行下载文件或覆盖当前文件夹。

## 常见问题

### 持续提示重新连接

部分电脑的连接失败和断联问题仍未全部解决。请核对 Windows 蓝牙及软件中的设备状态，并导出日志、注明发生时间。普通按键可用不代表语音服务已连接。

### 提示语音资源清理未完成

从通知区域“完全退出”后重新打开，再启动服务。

### 谷歌提示“只支持一个蓝牙适配器”

谷歌服务目前需要 Windows 只识别到一个可用蓝牙适配器。该提示也可能由没有识别到可用蓝牙触发，请先核对 Windows 蓝牙状态。

### 已配对，但设备列表里找不到

先确认 Windows 蓝牙设置中仍能看到遥控器，再到“选择设备”点击“刷新”。只有受支持的型号才能使用；有多只设备时需明确选中一只。

`.102/.103` 提示“读取设备失败”时，可使用[设备读取报告脚本](scripts/collect-device-read-report.cmd)：

1. 打开报错的无线麦版本，停在报错界面。
2. 把脚本放在该版本 EXE 旁，双击运行，等待显示完成；通常约 30～90 秒。
3. 将桌面生成的 `无线麦设备读取报告-时间-短编号.txt` 发给开发者，无需另导日志。

脚本不改配对、驱动或软件设置，不自动上传。报告包含系统和蓝牙诊断信息，请仅用于排查反馈。

### 方向键正常，自定义映射不生效

检查“按键接收”状态。提示权限或管理员组件异常时，按页面入口修复并确认 UAC；提示需要重启电脑时，保存工作后重启。

### 输入法有气泡，但没有声音

确认无线麦选 `CABLE Input`、输入法麦克风选 `CABLE Output`，再运行“检查虚拟声卡”。两边不能选反或选成同一个端点。

### 语音键没有唤起输入法

搜狗、微信和豆包：先在同一输入框用实体键盘测试快捷键。键盘也不生效时，检查输入法设置和快捷键冲突；键盘正常时，再核对无线麦的模式和快捷键。

Chatterfly：确认程序已运行且没有另一段录音；仍失败时导出日志反馈。

### 微信提示“已收到声音，未确认微信开麦”

程序收到了遥控器声音，但未确认微信开始录音。文字正常出现时无需处理；没有文字时，先松开话筒键，再按住重试。

### Chatterfly 有气泡但没有文字，或远程窗口输入异常

先在本机记事本中测试，并确认麦克风为 `CABLE Output`。本机正常、远程窗口异常时，反馈所用远程软件；这类兼容问题尚未全部解决。

### 反馈问题

在“设备”页的“诊断日志”一行点击“导出日志”，提供问题发生时间、实际使用版本、遥控器型号和语音程序。旁边的“打开日志位置”可打开日志文件夹；提示日志不完整时请一并说明。

导出内容不包含录音、输入正文或用户配置；公开反馈前仍请检查设备标识和个人路径。

## 配置、日志与卸载

用户配置和日志位于：

```text
%LOCALAPPDATA%\RemoteMic\RC003
```

- 同机同一 Windows 账户下升级会沿用原设置。
- 按键方案的副本和导出文件会包含预设文字、程序完整路径，请注意隐私。
- 旧版不识别新增的“输入文字”“打开程序”动作；回退时使用添加这些动作前的配置备份。
- 删除免安装程序文件夹不会自动删除这里的数据。若开启过“随 Windows 启动”，移动或删除程序前先关闭该选项。
- 要完全清除设置，请先完全退出无线麦，再删除上述配置目录。

## 支持范围与限制

- 支持小米遥控器2 Pro 和首页图示谷歌 Chromecast 遥控器；其它硬件版本的兼容性需先确认。
- 部分电脑的连接失败、断联、设备列表缺失及首次语音异常仍未全部解决。
- 程序未签名，受管理的公司电脑可能禁止 UAC、按键组件或虚拟音频安装。
- 管理员按键组件要求当前登录账号本身属于管理员组。
- 游戏或反作弊软件可能限制模拟按键，请按目标软件规则使用。
- 输入法的联网、识别和文字润色由输入法自身决定。

## 隐私与第三方组件

配置和日志保存在本机。无线麦不向项目服务器上传遥控器地址、按键记录、录音或个人数据；输入法是否联网由输入法自身决定。
