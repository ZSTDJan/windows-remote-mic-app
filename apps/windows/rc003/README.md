# 无线麦 Windows 使用说明

无线麦把小米蓝牙语音遥控器 2 Pro（RC003）和谷歌 Chromecast 遥控器变成
Windows 的远程按键和语音输入设备。

**[下载页面与最新版说明](https://github.com/ZSTDJan/windows-remote-mic-app)**

本页介绍当前正式版的使用方法。支持设备和界面预览见下载页面，历史版本可在
[Releases](https://github.com/ZSTDJan/windows-remote-mic-app/releases) 中查找。

## 下载与运行

- 系统要求：64 位 Windows 10 1809 或更高版本。
- 当前使用免安装 ZIP。请完整解压到一个新文件夹，再运行文件夹顶层的无线麦 EXE；
  不要只把 EXE 单独取出来。
- 程序暂未签名，首次运行可能出现 Windows SmartScreen 提示。请从本仓库下载，并用
  同一次发布中的 `SHA256SUMS.txt` 核对 ZIP。
- 如果旧版正在运行，先从通知区域图标选择“完全退出”，再打开新版。

核对哈希：

```powershell
Get-FileHash -Algorithm SHA256 .\RemoteMicRC003-<版本号>-portable-unsigned.zip
```

输出的哈希应与 `SHA256SUMS.txt` 中同名文件完全一致。

## 第一次使用

### 1. 在 Windows 中配对遥控器

先打开 Windows“设置 → 蓝牙和设备”，让遥控器进入配对状态并完成配对。

小米遥控器 2 Pro 可同时长按“主页键 + 菜单键”进入配对状态。谷歌遥控器不同版本的
配对方式可能不同，请按实物型号说明操作。

### 2. 在无线麦中选择设备

1. 打开“设备”页，点击“选择设备”。
2. 选中刚配对的遥控器，点击“使用此设备”。
3. 点击“启动服务”，按页面提示处理黄色或红色状态。
4. 状态显示已连接后，按一次方向键或确定键确认按键可用。

软件会记住选中的那一只遥控器。切换设备时会先停止当前按键和录音，再连接新设备。

### 3. 设置按键

打开“按键”页，选择实体按键，再设置单击、双击或长按动作。点击“完成”后自动保存。

- 方向、确认、返回、音量、翻页、快捷键和 Quicker 动作可按界面选项配置。
- 普通长按动作只触发一次；允许连续执行的普通动作在持续按住时会重复。
- 只有实体话筒键可以传送遥控器声音，其它按键不能改成语音键。
- 按键接收需要管理员组件时，程序会弹出一次 UAC。取消后自定义映射不会生效，
  可回到“设备”页重新启用或修复。

#### 鼠标长按与按键配置

“长按”栏可选鼠标左键、右键、X1、X2 长按：按住约 0.55 秒后保持鼠标按下，
松开遥控器按键即释放。

点击“恢复内置默认”旁的“管理按键配置”，可保存和切换不同用途的按键方案：

- 平时改键会自动保存到列表中的“自动保存”项。要保留一套方案，选中它并点击“复制配置”命名保存；之后改键不会改变副本。
- 选中方案并点击“应用配置”，确认后替换当前映射；仅浏览列表不会切换。正在使用的方案会加粗并带勾。
- 可重命名、删除副本，或通过导出／导入 JSON 文件备份。导入只加入列表，仍需点击“应用配置”才生效；重名时自动加序号。
- 配置按遥控器型号区分，只包含按键动作和备注，不包含蓝牙配对、语音或音频设置。
- “自动保存”项不能删除；删除副本也不会清除当前映射。如果提示旧动作需要调整，先回到按键页修改并保存，再复制、导出或应用。

### 4. 设置语音

如果要把遥控器声音送进搜狗、微信、豆包或 Chatterfly，需要安装并配置 VB-CABLE：

1. 打开“语音”页，点击“安装音频”，按提示安装后重启电脑。
2. 无线麦的“输出端点”选择 `CABLE Input — Windows WASAPI`；没有 WASAPI 时，
   可选 `Windows DirectSound`。
3. 在输入法的麦克风设置中选择 `CABLE Output`。
4. 在无线麦中选择语音程序。搜狗、微信和豆包需核对“语音按键”与输入法对应模式的快捷键一致；
   自动读取失败时，可刷新或手动录入。Chatterfly 直接控制录音，无需用快捷键唤起。
5. 打开记事本。使用搜狗、微信或豆包时，先用实体键盘测试语音快捷键，确认能正常录音和输入文字。
6. 保持光标在文字框内，再用遥控器话筒键测试。

`CABLE Input` 是无线麦写入声音的一侧，`CABLE Output` 是输入法读取麦克风的一侧，
方向不能互换。不要选择 `Windows WDM-KS`。

小米遥控器只支持按住型：按住说话，松开结束。谷歌遥控器还支持开关型：按一次开始，
再按一次结束；自动结束时长可选 1、2、3、5 或 10 分钟。开关型还需要输入法本身配置
对应的开关型快捷键；Chatterfly 的直接控制见下文。

Chatterfly 支持小米按住型及谷歌按住型／开关型，结束录音后气泡应消失。
界面中的语音快捷键可供键盘对照，不影响遥控器直接开始／结束录音。

搜狗、豆包和 Chatterfly 的自动快捷键会在切换设备、模式或进入语音页时重新读取。
手动录入的值不会被自动替换，需要主动刷新；微信也须主动刷新才会打开设置读取快捷键。

使用快捷键的按住型录音期间，语音快捷键会一直保持按下，松开话筒键才释放。请避开 Windows 和其它
软件已经占用的组合键，录音时不要同时操作其它键或鼠标。

## 日常使用

- 关闭设置窗口默认只是隐藏到通知区域，遥控器服务继续运行。
- 需要真正结束程序时，右键通知区域图标并选择“完全退出”。
- “随 Windows 启动”和“启动程序时自动运行服务”是两个独立选项，可分别设置。
- 服务断开时先按设备页提示“立即重连”或“重新连接”，无需反复启动多个程序。
- “检查更新”只提示和下载新版本，不会自动运行下载文件或覆盖当前文件夹。
- 更新时先完全退出旧版，把新 ZIP 解压到新文件夹，再打开新版。

## 常见问题

### 持续显示“点击重新连接”

部分用户的这类反馈仍在排查，1.0.95 尚未确认解决。该版补全了小米连接各步骤的日志，
保持原连接和重试规则；升级后仍有问题时，请按下方方法提供日志和发生时间。
普通按键能用，也不代表语音服务已经连接成功。

### 提示语音资源清理未完成

1.0.95 包含清理失败后的启动保护：检测到资源未清理完时，会阻止在同一次程序运行中
再次启动服务或进行声音测试。请从通知区域完全退出后重新打开，再启动服务。
这项保护不能说明豆包首次语音启动偶发异常已经解决，该问题仍待确认。

### 谷歌提示“只支持一个蓝牙适配器”

谷歌服务目前要求 Windows 只识别到一个可用蓝牙适配器。该提示也可能由没有识别到
可用蓝牙触发，不能仅凭提示认定电脑装了多个蓝牙；请先核对 Windows 蓝牙状态。

### 已配对，但设备列表里找不到

确认 Windows 蓝牙设置中仍能看到该遥控器，然后在“选择设备”窗口点击“刷新”。
软件只列出已支持的型号；有多只同类设备时，需要明确选择，不会自行猜测。

### 普通方向键有反应，自定义映射没有反应

检查“设备”页的“按键接收”状态。若提示权限或管理员组件异常，按页面入口修复并确认
UAC；若明确提示需要重启电脑，请保存工作后重启 Windows。

### 输入法能弹出气泡，但没有声音

检查无线麦是否选择 `CABLE Input`，输入法麦克风是否选择 `CABLE Output`，再运行
“检查虚拟声卡”。两边选反或选成同一个端点都会失败。

### 遥控器按语音键没有唤起输入法

搜狗、微信和豆包：先在同一个文字框中用实体键盘测试语音快捷键。键盘也无法唤起时，
先处理输入法设置或快捷键冲突；键盘正常、遥控器失败时，再核对无线麦的模式和快捷键。

Chatterfly：确认程序已运行，且没有另一段正在进行的录音；仍失败时导出日志反馈。

### 微信提示“已收到声音，未确认微信开麦”

这表示无线麦收到了遥控器声音，但未能确认微信本轮开始录音，不代表微信一定启动失败。
若文字正常出现，无需处理；若没有文字，先松开语音键，再按住重试。按住期间程序不会
因为查不到开麦状态而自行松键重按。

### Chatterfly 出现录音气泡，但没有文字

这类反馈尚未确认解决。先核对 `CABLE Output`，并在本机记事本中测试；仍无法输入时，
可暂时换用其它支持的输入法，并按下方方法提供日志。

### 豆包或微信在远程控制窗口表现不同

部分远程控制窗口会影响输入法气泡或文字上屏。先在本机记事本验证，再判断是否属于远程
软件兼容问题。

### 仍然无法定位

在“设备”页的“诊断日志”一行点击“导出日志”，同时提供问题发生的大致时间、
遥控器型号和所选输入法。导出内容不包含录音、输入正文或用户配置；公开反馈前仍请检查设备标识和个人路径。
旁边的“打开日志位置”可打开本机日志文件夹。若提示日志不完整，请一并说明。

## 配置、日志与卸载

用户配置和日志位于：

```text
%LOCALAPPDATA%\RemoteMic\RC003
```

删除免安装程序文件夹不会自动删除这里的数据。若开启过“随 Windows 启动”，移动或删除
程序前先在设备页关闭该选项。需要完全清除设置时，先完全退出无线麦，再自行删除上述目录。

## 当前限制

- 谷歌遥控器存在多个硬件版本，请按首页设备参考核对型号。
- 程序未签名，受管理的公司电脑可能禁止 UAC、按键组件或虚拟音频安装。
- 管理员按键组件要求当前登录账号本身属于管理员组。
- 游戏或反作弊软件可能把模拟按键识别为自动化操作；请按目标软件规则使用。
- 输入法的联网、识别结果和文字润色由输入法自身决定。

## 隐私与第三方组件

无线麦不会把遥控器地址、按键记录、录音或个人数据上传到项目服务器。配置和日志保存在
本机；所选输入法是否联网由输入法自身决定。

VB-CABLE 是 VB-Audio 的独立 Donationware。代码与第三方说明见
[`ATTRIBUTION.md`](ATTRIBUTION.md)、仓库根目录
[`THIRD_PARTY_NOTICES.md`](../../../THIRD_PARTY_NOTICES.md) 和
[`ASSET_LICENSES.md`](../../../ASSET_LICENSES.md)。
