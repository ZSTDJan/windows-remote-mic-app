# BUG-022：自定义组合键长按时意外重复

状态：代码已修复，待当前候选真机复测。

## 现象

用户把方向键映射为 `Shift+3` 后持续按住，前台出现光标或输入异常。此前已经
通过 `BUG-020` 修复原始方向键自动重复漏出，但映射层仍会把自定义组合键当作
可重复动作，按定时器反复执行完整组合键点按。

这不等于组合键一定没有抬起；日志没有发现持续按住不释放的证据。但反复重放
修饰键组合本身不符合“一个遥控器按键触发一次快捷键”的常见预期，也扩大了
异常或部分输入失败时的风险。

## 修复

- 长按重复改为显式白名单，只允许方向、退格和系统音量加减。
- 自定义组合键、应用启动、菜单、桌面、播放暂停等动作每次实体按下只执行
  一次完整点按。
- 原有双击或长按手势仍按各自配置执行，不受本次“持续按住自动连发”规则影响。

## 自动验证

- `action_allows_repeat()` 逐一覆盖所有动作类型。
- 方向键映射为 `Shift+3` 后，按下只执行一次并且不创建重复定时器。
- 方向、退格和音量动作仍保留重复资格。
- 2026-08-22 完整 unittest：1149 项通过，7 项按平台或安全条件跳过。

## 真机复测

1. 上键保持“方向上”，持续按住，确认焦点或光标正常连续移动，松手立即停止。
2. 上键改为 `Shift+3`，短按和长按都只能产生一次 `#`，不能跳到行首或持续输入。
3. 返回键和音量加减持续按住，确认仍按预期连续执行且松手后没有残留按键状态。
