# BUG-020：长按遥控器按键时原始方向键重复漏出

## 现象

把遥控器“上”映射为 `Shift+3` 后，短按可以输入 `#`；持续按住时，光标会先
回到行首，再继续出现映射结果。用户反馈的“组合键像没有正常抬起”实际包含了
另一个问题：遥控器原始的“上方向键”仍在前台自动重复。

## 真机证据

日志显示设备侧只有一次“上方向键按下”和一次“上方向键抬起”。第一次 Windows
按下记录能与设备记录匹配并被拦截；约半秒后，Windows 开始每 60 至 80 毫秒
产生重复按下，旧逻辑均记录为 `matched=False`。设备已经报告松手后，排队的
重复按下还继续到达，最后才出现 Windows 抬起记录。

这说明映射的 `Shift+3` 本身不是根因。旧拦截器只保存“等待匹配的一条边沿”，
没有保存“这个遥控器键仍处于按住状态”，所以第一条被吞掉后，其余自动重复会
原样送给当前输入框。

## 修复

- 设备侧按下时，同时保存这个实体键的按住状态；
- 按住期间，同一键的 Windows 重复按下全部拦截；
- 设备侧抬起后进入短暂收尾，继续拦截已经排队的重复按下；
- 收到 Windows 对应抬起后立即清除状态；
- 若抬起记录丢失，状态由安全期限自动清除，避免长期影响普通键盘；
- 软件注入的映射按键、其他实体键和无关键不受影响。

## 验证边界

自动测试覆盖连续重复按下、设备先抬起但 Windows 重复晚到、Windows 抬起后
恢复、其他键放行和注入键放行。自动测试不能代替真机长按复测；候选包仍需在
记事本中验证短按与长按 `Shift+3`，并确认松手后普通键盘方向键立即恢复。
