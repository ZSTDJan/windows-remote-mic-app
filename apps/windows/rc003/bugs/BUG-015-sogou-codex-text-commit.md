# BUG-015 搜狗语音可向记事本上屏但不能向 Codex 输入框提交

状态：待区分宿主兼容与快捷键焦点时序，尚无代码修复

记录日期：2026-08-21

## 现象

同一轮 RC003 语音测试中，搜狗能够识别并把文字提交到记事本，但在 Codex
输入框中没有上屏。

## 当前边界

Remote Mic 只负责两件事：向当前前台宿主发送配置的搜狗语音快捷键，以及把
RC003 PCM 播放到 CABLE Input。识别后的文字属于搜狗进程；本程序不接收识别
结果，也不直接向目标输入框写文字。因此 `app.log` 可以证明快捷键、PCM 和
设备状态，不能证明搜狗最终向哪个控件提交了文字。

记事本能够上屏已经证明音频链和搜狗识别至少在一个标准 Win32 文本框中可用，
但不能自动证明 Codex 的输入控件与搜狗语音提交方式兼容。

## 区分测试

1. 保持 Codex 输入框获得焦点，不按遥控器。
2. 直接用键盘按与软件完全相同的搜狗免按快捷键，讲话后用键盘结束。
3. 如果仍不能上屏，问题位于搜狗语音与 Codex 输入控件的兼容边界，本软件
   调整 RC003 时序不会产生识别文字的控制权。
4. 如果键盘手动触发可以上屏，而遥控器触发不行，再对比快捷键交付前后的
   前台窗口与焦点时序；届时才把它升级为本程序的宿主触发故障。

本记录不包含用户语音内容或输入框内容。
