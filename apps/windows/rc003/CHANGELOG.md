# Changelog - 无线麦 RC003 (Windows)

## [0.2.0-candidate.1] - 2026-09-01

首次整理后的公开候选版本：

- 支持小米遥控器2 Pro（RC003）的 BLE/ATVV 连接、按住说话和 13 键映射；
- 支持 Raw Input 与可选 HID 旁路、单击/双击/长按和遥控器组合动作；
- 支持 VB-CABLE 通道检查，以及搜狗、微信和 Windows 语音输入；
- 提供 Qt Quick 设置界面、通知区域、登录启动、自动启动桥接和完整退出；
- 提供元素导航、窗口操作、快捷键和常用系统动作；
- 补齐 GPL、第三方许可、素材授权、公开隐私检查和 Windows CI 发布门禁。

候选产物未签名。安装器、便携版和 `SHA256SUMS.txt` 必须来自同一次 CI 构建。
