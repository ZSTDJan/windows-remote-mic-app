无线麦（Windows 源码/构建候选）
====================================================

状态：本安装包是 `0.2.0-candidate.1` 未签名候选。用户已确认现有功能完成
真实小米遥控器2 Pro 使用验证；当前产品只支持实体话筒键按住说话。

系统要求
--------
- Windows 10 1809（内部版本 17763）或以上，64 位；
- 未签名安装包：首次运行时 Windows SmartScreen 可能提示"Windows 已保护你
  的电脑"。这是预期行为，不是错误——本项目目前没有购买代码签名证书。

  在点击"仍要运行"之前，建议先核对安装包（或便携版 ZIP）的 SHA-256 校验
  值是否与同一次构建产出的 SHA256SUMS.txt 一致。以 PowerShell 为例（把
  <文件名> 换成你实际下载的文件名，例如
  RemoteMicRC003Setup-0.2.0-candidate.1-unsigned.exe）：

      Get-FileHash -Algorithm SHA256 .\<文件名>

  把命令输出的 Hash 值（不区分大小写）与 SHA256SUMS.txt 中同一个文件名
  那一行的哈希值逐字比较：一致才继续安装；只要有一个字符不一致，就不要
  运行这个文件——重新下载，或联系发布者核实来源。哈希核对一致后，再点击
  SmartScreen 提示中的"更多信息"，然后点击"仍要运行"。

安装
----
1. 运行 RemoteMicRC003Setup-<版本号>-unsigned.exe；
2. 安装程序只安装到当前用户目录（%LOCALAPPDATA%\RemoteMic\RC003），
   不请求管理员权限，不设置开机自动启动，不安装任何驱动；
3. 安装完成后可以勾选"打开 无线麦 设置"。程序只打开统一的桌面设置窗口；
   需要使用遥控器服务时，在"设备"页点击"启动桥接"。关闭窗口默认隐藏到
   通知区域，不会直接结束后台服务。

配对小米遥控器2 Pro
-------------------
1. 同时长按遥控器的【主页键】+【菜单键】，直到遥控器进入配对广播状态；
2. 打开 Windows"设置 → 蓝牙和其他设备"，等待遥控器出现后完成配对；
3. 本程序按蓝牙名称自动查找已配对设备，不需要手动输入地址；如果找到 0 个
   或超过 1 个匹配设备，程序会拒绝猜测并报错退出，而不是随意连接一个。

（可选）安装 VB-CABLE 作为虚拟麦克风
------------------------------------
本程序不会静默下载、安装、启用或卸载任何虚拟音频驱动，也不会修改 Windows
默认输入/输出设备。如果你想让语音识别/听写软件把小米遥控器2 Pro 的语音
当作一个"麦克风"来使用，可以在"语音"页明确点击"安装虚拟音频"，也可以
自行从 VB-Audio 官方网站下载并安装官方 VB-CABLE：

  https://vb-audio.com/Cable/

安装完成后按下面的方向手动配置——方向不能弄反：

  - 无线麦的"输出端点"（语音输出设备）设置项  →  优先选择
    "CABLE Input — Windows WASAPI"，没有时选择
    "CABLE Input — Windows DirectSound"（VB-CABLE 的虚拟"扬声器"一侧）；
  - 语音识别/听写软件的麦克风输入设置          →  选择 "CABLE Output"
    （VB-CABLE 的虚拟"麦克风"一侧）。

不要选择 Windows WDM-KS：当前 PortAudio 阻塞播放 API 无法打开它，新版本
会隐藏并拒绝该视图，保存前还会实际打开一次端点。如果两边选成同一个名字，
或者方向选反了，语音功能会失败，但普通按键映射仍然正常工作。

随包安装（可选）：打开"语音"页，在"虚拟音频"一行点击"安装虚拟音频"。
程序会先说明 VB-CABLE by VB-Audio 是独立 Donationware，不属于本项目 GPL
代码；随包只提供基础版，不含付费的 A+B/C+D。确认后才会解压已经按固定
SHA-256 校验过的官方 VBCABLE_Driver_Pack45.zip，并通过 Windows 用户账户
控制 (UAC) 启动原始的 VBCABLE_Setup_x64.exe。本程序自身不以管理员身份
运行，UAC 可以取消，取消不会安装任何内容。安装完成后重启电脑，再回到
"语音"页点击"应用"，程序会选择检测到的 CABLE Input。这个入口只是把
手动下载安装换成随包、离线、明确确认的流程；仍可直接从
https://vb-audio.com/Cable/ 手动下载安装。

安装目录还包含 THIRD_PARTY_NOTICES.md、THIRD_PARTY_SOURCE.md、
ASSET_LICENSES.md 和 THIRD_PARTY_LICENSES 文件夹，用于说明随包组件、对应
源码、素材授权和完整许可证。它们与程序本体属于同一次发布，不能单独删除后再分发。

首次使用
--------
1. 从 Start Menu 打开"无线麦"或"无线麦 设置"。统一设置窗口只有
   “设备”“按键”“语音”三个页面：
     - “设备”页显示小米遥控器2 Pro、按键接收、遥控器服务、运行日志和桌面行为；
     - “按键”页设置 13 个实体按键的单击、双击、长按和遥控器组合；
     - “语音”页设置虚拟音频、输出端点、语音程序、语音按键和声音测试。
2. 如果使用 VB-CABLE，在“语音”页确认“输出端点”为 CABLE Input。安装后
   可以在“虚拟音频”一行点击“应用”自动选择检测到的端点，也可以手动从
   下拉框选择；程序不会修改 Windows 默认输入/输出设备。
3. 在“按键”页完成映射后点击“保存映射”。恢复内置默认只改变当前界面，仍要
   保存后才会写入。实体话筒键可设为“按住说话”，也可以改成普通动作；其它
   按键只能使用普通动作。
4. 在“语音”页选择语音程序和语音按键。当前每个语音程序分别记忆自己的按住
   说话快捷键；Windows 语音输入固定使用 Win+H。搜狗和自定义程序可以选择由
   无线麦启动，只有用户明确开启管理员启动时才会出现 UAC；取消或启动失败不会
   阻止遥控器服务。
5. 回到“设备”页点击“启动桥接”。这个按钮只使用已经保存的设置，不会顺带保存
   其它页面尚未应用的修改。界面会显示正在启动、等待小米遥控器2 Pro、已连接或
   启动失败等真实状态。启动后，Windows 通知区域会出现无线麦图标；双击可恢复
   窗口，右键可打开设置或“完全退出”。关闭窗口默认只是隐藏到通知区域。
   “运行日志”一行的“日志目录”可打开
   %LOCALAPPDATA%\RemoteMic\RC003\logs；程序从未运行过时会如实提示目录不存在。
6. 按方向键或确定键验证普通映射。按键页的检测和自动检查只能证明收到事件，
   不能替代真实软件中的操作结果。
7. 测试话筒键前，先打开记事本或任意可编辑文本框，把光标放进输入区域，手动按
   一次当前语音程序配置的快捷键，确认语音界面出现并能输入文字。语音程序或
   Windows 的麦克风输入应选择 CABLE Output。手动快捷键通过后，再按住遥控器
   话筒键说话，松开后检查是否输入文字。程序只执行按住开始、松手结束；宿主软件
   如果不能用实体键盘正常收尾，需要先调整宿主自己的快捷键或语音模式。

   单独排查 Windows 系统听写时，手动按 Win+H。这一步需要同时满足：光标位于
   可编辑文本框；Windows 已启用“联机语音识别”（Windows 11：
   设置 → 隐私和安全性 → 语音；Windows 10：设置 → 隐私 → 语音）；系统麦克风
   输入选择 CABLE Output。Win+H 只验证 Windows 听写，不能替代其它语音程序的
   快捷键验收。

停止 / 重启
-----------
- 关闭主窗口默认只隐藏到通知区域，不会停止后台服务；
- 右键通知区域的无线麦图标并选择“完全退出”，程序会先正常停止遥控器服务，
  再清理 BLE、HID、语音热键与音频资源。停止失败时会恢复窗口并明确提示，
  不会假装已经退出；
- Start Menu 的“停止 无线麦”可作为外部停止入口；重新打开“无线麦”，在
  “设备”页点击“启动桥接”即可再次启动。

卸载
----
从 Windows"设置 → 应用"，或 Start Menu 的"卸载 无线麦"
条目卸载。卸载过程会先自动停止正在运行的桥接进程，再删除安装时写入
的程序文件；不会触碰你系统上的蓝牙配对记录，也不会触碰你自行安装的
任何虚拟音频驱动。

卸载不会自动删除设置和日志：config.json、key_bindings.json 和
logs\app.log 会一直保留在 %LOCALAPPDATA%\RemoteMic\RC003 下，因为
安装脚本没有为这些运行期生成的文件配置卸载删除规则。如果这台
电脑上不会再安装任何 RC003 版本（安装器或便携版）、也不需要
保留这些设置和日志，可以在卸载完成后手动删除整个
%LOCALAPPDATA%\RemoteMic\RC003 文件夹；如果还会用到
同一台电脑上的另一个 RC003 安装，请不要删除这个共享目录。

默认按键映射
------------
  麦克风         按住说话；新配置默认右侧 Alt，松开结束
  电源           Escape
  上 / 下 / 左 / 右   对应方向键
  确定（OK）      Enter
  返回           退格（Delete）
  音量 + / −      系统音量 + / −
  主页           Win+D
  菜单           Shift+F10
  TV             Alt+Esc

以上每一行都可以在设置窗口"按键"页中重新指定并保存；但只有实体话筒键
可以选择“按住说话”。话筒键也可以改成普通动作。

物理按键与固定行为
------------------
- 小米遥控器2 Pro 一共有 13 个物理按键：12 个普通按键（电源、上/下/左/右、确定、
  返回、音量+/-、主页、菜单、TV）再加上 1 个话筒按键；
- 只有实体话筒键可以驱动遥控器传声，也可以将它改为普通动作。开关型语音、
  其他按键上的旧语音动作或次级语音动作升级后会整键停用，必须重新选择并
  保存，程序不会把旧配置自动改成按住说话；
- 方向、退格和音量动作允许长按连续执行；自定义组合键始终只执行一次完整
  点按，不随长按定时重复；
- 遥控器没有独立的物理静音键："系统静音"只是可以手动分配给其他按键的一
  个可选动作，不是任何按键的默认映射；
- "返回"键默认映射为退格动作。如果某台 Windows 设备交付了未识别的 Raw Input
  签名，需要使用源码包中的被动按键采集/回放流程学习物理签名；不要直接猜测
  扫描码，也不要把 HID 路径或蓝牙地址写入设置。

不包含内容
----------
- 不包含任何输入法或语音识别功能；
- 不包含 T1、V60/PV60 或其他设备的桥接程序；
- 安装器不会静默安装或配置任何音频驱动；候选可携带经固定 SHA-256 校验的
  VB-Audio 官方原始 VB-CABLE Basic 压缩包，仅在用户从“语音”页明确
  确认并接受独立 UAC 提示后启动厂商安装程序；
- 不会以管理员身份运行，安装时不会请求提权；
- “随 Windows 启动”和“启动程序时自动启动桥接”默认关闭，只有用户在
  “设备”页明确开启后才生效，两者互不绑定。
