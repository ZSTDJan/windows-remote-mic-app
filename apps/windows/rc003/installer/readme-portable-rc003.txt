无线麦便携版 - 小米遥控器2 Pro Windows 客户端
================================================

这是解压即用的便携版，不是安装程序。请先完整解压整个 ZIP，再双击解压目录
根层唯一的“无线麦 win版 <版本号>.exe”。根层另外两个文件夹是“程序文件”和
“说明与许可”；不要单独复制 EXE，也不要移动、改名或删除“程序文件”中的组件。
“说明与许可”只放使用说明、许可和来源资料，不参与程序运行。

切换旧版
--------
如果同一 Windows 登录会话中已有其它目录或旧版本的无线麦运行，当前版本会明确
询问是否切换。选择“是”后：

- 支持正常退出请求的旧版会处理未保存提示并自行退出；用户取消退出时，当前
  版本会停止切换，不会继续假等待；
- 更早的旧版如果 5 秒内没有接收退出请求，当前版本会立即提示从右下角通知区域
  右键无线麦并选择“完全退出”；
- 旧版完全退出后，这次双击的当前版本会自动继续打开。

程序不会强制结束旧版，也不会丢弃未保存的按键修改。较早版本无法回传取消结果时，
当前版本会在有界等待后停止，不会一直没有反应。用户取消、旧版未退出、
退出状态无法确认或切换请求无法安全清理时，当前版本不会启动。窗口标题会显示
当前版本号，可用来确认最终打开的是哪一版。

基本使用
--------
1. 首次使用本版，先在“设备”页点击“选择设备”，添加已在 Windows 配对的小米
   遥控器或 谷歌 Chromecast 遥控器，再点“使用此设备”。软件只接收已添加且当前选中的这一只，旧按键映射
   和语音设置保留。随后在“语音”页选择输出端点、语音程序和语音按键。
2. 在“设备”页点击“启动服务”，或按需要开启程序启动后自动启动遥控器服务。
3. 关闭窗口默认隐藏到通知区域，遥控器服务继续运行；需要点关闭就结束整个
   程序时，可在“设备”页改为“完全退出”。
4. 需要完全退出时，也可右键通知区域的无线麦图标并选择“完全退出”。

检查更新
--------
程序启动约 5 秒后静默检查本项目 GitHub Releases，每个自然日最多自动检查一次，
失败也计入，同日重启不重复。有新版时只提醒，点击后才打开下载对话框；无新版或
联网失败不打扰用户。也可在“设备”页点击“检查更新”，手动检查不受每天次数限制，
不需要 GitHub 账号或令牌。

便携版会下载同一次 Release 的便携 ZIP，并核对 SHA256SUMS.txt；GitHub 提供资产摘要时
也会一并核对。最新版文件未上传完整时直接提示，不会推荐旧版本。下载先保存在
%LOCALAPPDATA%\RemoteMic\RC003\updates\<版本号> 缓存，校验后把完整文件放到 Windows
实际桌面；同名同内容复用，不同内容加序号，不覆盖已有文件。只清理自己的过期缓存，
不清理桌面更新包。桌面不可写时保留已校验缓存并提示重试。

下载完成后提供“打开桌面”，不会覆盖当前解压目录。请先完全退出无线麦，
再把 ZIP 解压到新的文件夹使用；取消、中断或校验失败不会改变当前程序。

权限与自启动
------------
请直接双击打开主程序。程序会按当前进程的实际权限选择按键路径：已有管理员权限时
直接打开，包括已关闭 UAC 或系统默认以管理员权限运行的情况，不再要求安装当前运行
不需要的管理员按键组件；普通权限下，需要管理员权限的组件操作会单独请求 Windows UAC。
组件启用成功不代表真实遥控器和所有权限场景已经通过。

普通权限下，小米遥控器的管理员按键组件未启用时，程序会显示“建议打开管理员按键权限”：高亮按钮
是“打开”，旁边是文字按钮“不打开”。选择“打开”后会弹一次 Windows UAC；确认成功后，
主程序、以后普通启动和随 Windows 启动都保持普通权限，不再反复弹 UAC。选择“不打开”
或授权失败时，
全部自定义按键映射停用，只保留 Windows 原始按键操作；可在“设备”页“按键接收”
一行点击“启用改键”重试。当前登录账号需要本身属于管理员组，不能用标准账号临时
输入另一个管理员账号代替。随 Windows 启动可以在“设备”页开启，但移动或删除解压
目录会使该启动项失效。

选择谷歌遥控器时会自动准备蓝牙详细事件，按提示完成 Windows 管理员授权，无需额外开关。

数据与移除
----------
程序设置和日志位于 %LOCALAPPDATA%\RemoteMic\RC003，不在便携目录中，并与安装版及其它便携副本共用。
如果以后不再使用任何无线麦版本，先在“设备”页点击“移除权限”并确认一次 UAC，
再删除解压目录。“移除权限”会让当前 Windows 账号下所有无线麦版本的自定义按键映射
同时失效；以后从其它安装版或便携版重新启用时，需要再次确认 UAC。直接删除解压目录
只会移除程序本体，不会自动移除已授权助手，也不会删除这些设置和日志。只有确定
以后不再使用任何 RC003 版本时，才手动删除该 LocalAppData 目录。
