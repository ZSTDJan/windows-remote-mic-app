无线麦便携版 - 小米遥控器2 Pro Windows 客户端
================================================

这是解压即用的便携版，不是安装程序。请先完整解压整个 ZIP，再双击解压目录
根层唯一的 RemoteMicRC003.exe。不要单独复制 EXE，也不要手动打开 _internal
目录中的组件。

切换旧版
--------
如果同一 Windows 登录会话中已有其它目录或旧版本的无线麦运行，当前版本会明确
询问是否切换。选择“是”后：

- 支持正常退出请求的旧版会处理未保存提示并自行退出；
- 更早的旧版会被唤到前台，请从右下角通知区域的无线麦图标选择“完全退出”；
- 旧版完全退出后，这次双击的当前版本会自动继续打开。

程序不会强制结束旧版，也不会丢弃未保存的按键修改。用户取消、旧版未退出、
退出状态无法确认或切换请求无法安全清理时，当前版本不会启动。窗口标题会显示
当前版本号，可用来确认最终打开的是哪一版。

基本使用
--------
1. 首次打开后，在“语音”页选择输出端点、语音程序和语音按键。
2. 在“设备”页点击“启动桥接”，或按需要开启程序启动后自动启动遥控器服务。
3. 关闭窗口默认会先正常停止遥控器服务并完全退出；需要后台运行时，可在
   “设备”页改为“隐藏到通知区域”。
4. 需要完全退出时，也可右键通知区域的无线麦图标并选择“完全退出”。

权限与自启动
------------
便携版本身不会安装预授权 HID 助手。如果本机没有同版本安装版登记的助手，普通
权限启动时方向键只保留 Windows 原始操作一次，自定义方向映射不会执行；需要这项
能力时可手动以管理员身份启动便携版。随 Windows 启动可以在“设备”页开启，但移动
或删除解压目录会使该启动项失效。

数据与移除
----------
程序设置和日志位于 %LOCALAPPDATA%\RemoteMic\RC003，与安装版及其它便携副本共用。
删除解压目录只会移除程序本体，不会删除这些设置和日志。只有确定以后不再使用任何
RC003 版本时，才手动删除该 LocalAppData 目录。
