无线麦 Win10 兼容测试与接收组件诊断

1. 将整包解压到新目录，完全退出旧版，再打开本包无线麦。保留原有配置，无需重新配对。
2. 正常尝试启动遥控器服务。如仍报红，记下测试时间，进入“说明与许可”，双击“生成接收诊断报告.cmd”。
3. 等待约半分钟，将无线麦主程序旁最新的“无线麦接收诊断-日期-时间.zip”发给开发者。无需另装 Python。

这份报告会合并现有日志，检查临时目录能否创建、读写和删除测试文件，并读取最近 15 分钟的相关系统事件。
报告不包含用户配置或录音，不会自动上传，也不修改驱动、配对、杀毒设置或目录权限。具体错误中的本机路径和用户标识会隐去。
日志开关仍沿用原有设置；测试时请保持“诊断日志”开启。不要先删除旧日志。

本版用于测试，尚未确认解决反馈电脑的接收组件启动失败；没有相关系统事件也不能证明未发生拦截。
Win10 软件基础检查与真实蓝牙、遥控器、输入法语音测试分别记录。需要用反馈电脑确认正常语音、重连、停止和退出。
